# 问题—回应覆盖复核口径

`signal_lab.coverage` 把四类记录关联起来：被提出的问题、支持该问题的报道观察、
回应内容、编辑判断。复核者据此区分直接回应、部分涉及与仅仅主题相似，并查看
每种判断的依据。

## 关联结构

- **问题（Question）**：受众提出的问题，可关联多条支持它的报道观察。
- **报道观察（ReportObservation）**：支持该问题的报道观察。更正产生新版本，
  撤回是特殊的更正；全部历史版本保留备查。
- **回应（Response）**：对外回应。每次修订产生新版本，历史版本保留。
- **判断（Judgment）**：编辑对“某回应是否解答某问题”的结论，必须写明判断依据，
  并固定在判断时的回应版本上。

回应与问题之间只通过判断关联。关键词重叠仅用于 `find_candidate_responses`
推荐待判断候选，不构成任何覆盖结论。

## 判断类别

| 类别 | 含义 | 是否计入覆盖 |
| --- | --- | --- |
| 直接回应（direct） | 正面解答了问题 | 计为已回应 |
| 部分涉及（partial） | 只解答了问题的一部分 | 单列，不算已回应 |
| 仅仅主题相似（topical） | 主题相近但未解答问题 | 不计入 |

## 当前分析口径

当前分析（`assess_question` / `coverage_summary`）始终从最新记录实时推导：

- **已回应**：存在未撤销、且针对当前回应版本的“直接回应”判断。
- **部分回应**：无直接回应，但有满足同样条件的“部分涉及”。
- **未回应**：其余一切情况——只有主题相似、判断已撤销、回应在判断后
  有了新版本（旧判断标记为待复核），或从未判断。

因此：报道被更正后，当前分析立即使用新文本，全部支持观察被撤回的问题
标记为 `supported=False`；回应版本变化后，针对旧版本的判断不再计入；
判断被撤销后，记录与理由保留可见，但不再计入。未得到有效回应的问题
不会因为相关关键词出现过而显示为已解决。

## 复盘

`create_retrospective` 冻结创建时刻的问题文本、观察版本文本、判断所评估的
回应文本、全部判断（含已撤销及其理由）与当时的结论。之后的更正、修订与
撤销不影响复盘内容；复盘之间可以对照口径变化。
