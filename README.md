# 受众问题与传播回应观察

这个 Python 项目整理与“受众问题与传播回应观察”有关的来源观察，并生成供研究人员复核的统计摘要。

## 问题—回应覆盖复核

`signal_lab.coverage` 把受众问题、支持问题的报道观察、回应文本与编辑判断关联起来，
区分直接回应、部分涉及与仅仅主题相似，并保留每种判断的依据。当前分析随报道更正、
回应修订与判断撤销实时变化；复盘快照保留当时的文本版本与判断。关键词重叠只用于
推荐待判断候选，不计入覆盖。口径详见 `docs/coverage-review.md`。

## 开发

需要 Python 3.11 或更高版本。安装开发依赖：`python -m pip install -e .`。

运行测试：`python -m unittest discover -s tests -v`。
构建发行包：`python -m build`。
